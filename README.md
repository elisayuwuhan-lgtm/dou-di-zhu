# Private Dou Di Zhu tabletop
Requires Node.js 18+. Run `npm install` then `npm start` in this folder. Open http://localhost:3000. For friends on separate networks, deploy this folder to a permitted Node.js hosting provider supporting WebSockets, using `npm install` as build command and `npm start` as start command. Share the resulting HTTPS URL. Create a room and copy the invitation link. Three players are required. Agree on bidding and valid combinations yourselves; this is a virtual tabletop, not a full rules engine. Rooms live in memory and are reset when a player disconnects or the server restarts. No accounts or wagering. Use only on networks where games are permitted.
